# A Season of Making — Thirak's Portfolio

A responsive personal portfolio with a cinematic autumn / Hirara-inspired visual direction.

## Run locally
Open `index.html` in your browser. No build tools are required.

## Personalize before publishing
- Replace `hello@example.com` with your preferred email in `index.html`.
- Update the project links to their individual repository URLs.
- Confirm the education timeline and toolkit reflect your current progress.
- Optional: add a portrait or personal artwork to the About section.

## Deploy with GitHub Pages
1. Add these files to your portfolio repository.
2. Keep `index.html` in the repository root.
3. Open **Settings → Pages** on GitHub.
4. Select your branch and the root folder, then save.

Built with HTML, CSS, and vanilla JavaScript.
